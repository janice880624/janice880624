### 🏊‍♀️ 鐵人三項 AI 助理教練（研究原型）

碩士論文與實驗室計畫的核心：讓教練看得到「女性運動員的身體正在經歷什麼」。

| 專案 | 介紹 |
|------|------|
| **TriAsst 教練端監測平台** | 課表管理、體能表現報告、問卷趨勢追蹤與月經週期標記；PMC 引擎以 EWMA 計算 ATL／CTL／TSB，整合 MSI、POMS、PSS、PSQI、ABQ 等 10 種量表 |
| **TriGuide 運動員端** | 與 TriAsst 配對的運動員介面，回填問卷、查看自己的訓練負荷與恢復狀態 |
| **訓練負荷整合儀表板** | 統一 sRPE 與 TSS 兩套負荷，ACWR、急慢性負荷在同一張圖上對照 |
| **問卷資料篩選工具** | 從 Google Sheets 拉問卷資料，購物車式挑選、標記 T0／T1／T2 時間點，可存檔續作 |

## 🔬 研究

| 主題 | 內容 |
|---|---|
| **月經週期 × 心理生理反應** | 10 位女性鐵人、3 個週期 × 3 個相位的縱貫追蹤；以 LMM（lme4／lmerTest／emmeans）分析，並用 CLMM／GLMM 做穩健性檢驗 |
| **訓練負荷模型** | sRPE 與 TSS 雙軌負荷，比較 τ = 28 與 τ = 42 天慢性負荷的敏感度，探討與 PSS、PSQI、ABQ 等量表的關聯 |
| **探索性機器學習** | LassoCV ＋ leave-one-athlete-out 交叉驗證，嘗試以訓練負荷特徵預測問卷分數 |
| **長期方向** | **AI 助理教練** — 從「靠感覺」走到「看數據」，再走到「AI 幫教練先看一遍」 |
