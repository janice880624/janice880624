## 🙋‍♀️ 關於我

我是 Janice，在臺科大 **運動科學暨運動防護實驗室** 念碩士，同時擔任女性鐵人三項選手的 **助理教練**，為每位選手撰寫個人化訓練課表。

| 領域 | 主題 |
|---|---|
| **運動科學** | 鐵人三項訓練、訓練負荷監控、個人化課表 |
| **運動防護** | 運動傷害評估與處置、防護員檢定準備、急救與水上救生 |
| **資料分析** | R、Python、資料視覺化 |
| **工具開發** | 單檔 HTML 工具、Google Sheets／Apps Script 當後端、Firebase 登入、GitHub Pages 部署 |
